# GI Supervision Tracker

Een webapplicatie voor begeleiders van afstudeerders en stagiaires (GI = Graduation Internship) om het begeleidingsproces per student bij te houden en te structureren.

## Doel

Deze applicatie helpt docenten en begeleiders bij HBO Bedrijfskunde om het **supervisieproces van afstudeerders en stagiaires** overzichtelijk te beheren. Per student kunnen voortgang, begeleidingsgesprekken en actiepunten worden bijgehouden, zodat de begeleiding consistent en inzichtelijk verloopt.

## Functies

- **Groepenbeheer**: Studenten zijn georganiseerd in groepen. Begeleiders kunnen nieuwe groepen aanmaken en studenten toevoegen.
- **Studentenoverzicht**: Per groep een overzicht van alle studenten met hun voortgangsstatus.
- **Zoekfunctie**: Snel zoeken naar specifieke studenten via de zoekbalk.
- **Deze Week Overzicht**: Dashboard met een overzicht van geplande en afgeronde begeleidingsactiviteiten voor de lopende week.
- **Instellingen**: Configuratie van de tracker aan de wensen van de begeleider.
- **Lokale Opslag**: Gegevens worden opgeslagen in de browser zodat ze beschikbaar blijven bij herbezoek.

## Technologie

De applicatie is gebouwd met JavaScript en is beschikbaar als statische webpagina via GitHub Pages. Geen server of database vereist.
